# HomeBoard

A shared home board for couples and households: one calendar, one to-do list, one meal plan and grocery list, and a simple view of what you're spending — on every phone, tablet and laptop in the house.

> Status: **planning / v1 rebuild**. The original single-file prototype lives in [`reference/home-board-v1.html`](reference/home-board-v1.html) (all personal data removed). It was built to run inside Claude artifacts, so it won't save data when opened on its own — it's here as a design and feature reference only.
